# 🤖 CyberBot

A Discord bot developed in Python.

## 📌 Description

CyberBot is a simple Discord bot created as a Python learning project.
It includes several commands for interacting with users, displaying
server information, generating random results, and retrieving weather data
through an external API.

## ⚙️ Features

- 👋 Greeting command
- 🏓 Ping command
- 🤖 Bot information
- 🌍 Server information
- 🖼️ User avatar
- 🎲 Random number / dice commands
- 🪙 Coin flip
- 📅 Date and time
- 🌦️ Weather information using OpenWeather API

## 🛠️ Technologies

- Python
- discord.py
- python-dotenv
- Requests
- OpenWeather API
- Git / GitHub

## 🔐 Environment Variables

The bot uses a .env file to store sensitive information such as API keys
and the Discord bot token.

Example:

env
TOKEN=your_discord_token
WEATHER_API_KEY=your_openweather_api_key


## 🚀 Running the Bot

Install the required dependencies:

bash
pip install discord.py python-dotenv requests


Then configure the .env file and run:

bash
python bot.py


## 📚 Project Purpose

This project was created to practice Python programming, APIs,
environment variables, asynchronous programming, and Git/GitHub.
